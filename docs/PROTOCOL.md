# 协议与实现边界（v1）

## 配对

接收码由公共六位数字 locator 和四个随机单词组成。单词从 64 个唯一词中独立均匀选择，密码部分共 24 bit。locator 只用于查找房间，不计入密码熵。传输时通过自己的可信沟通渠道分享完整接收码。

客户端使用 `salsa.debian.org/vasudev/gospake2` 的 SPAKE2/Ed25519 实现（固定版本 `d91629950ad1`）。该库也被 Go 的 `wormhole-william` 客户端使用。这里复用其 PAKE 运算，不自行实现曲线或用普通密码哈希替代 PAKE。它不是本项目自称通过审计的密码库；上游明确说明未接受正式密码学审计，且依赖 `math/big`，不能宣称具备完整恒定时间实现保证。整个新组合也未经独立安全审计。

1. 发送方用部署邀请令牌创建房间，取得随机 session UUID，并在本地生成密码词。
2. 接收方使用 locator 领取房间。Durable Object 原子地固定一个 receiver token；同一 token 的网络重试幂等，其他 token 拒绝。
3. 两边分别使用 SPAKE2 A/B 角色，身份串包括应用域、session UUID 和 sender/receiver 角色。
4. 交换 33 字节公开 SPAKE2 消息。房间各角色的消息只允许写一次，完全相同的 HTTP 重试允许。
5. 派生的共享密钥通过 HKDF-SHA256 分离用途。双方发送角色分离的 HMAC-SHA256 确认，绑定会话和按 sender、receiver 排列的两条公开 SPAKE2 消息。
6. 双方都验证对方确认后，才交换加密 offer / accept 和开始文件数据传输。

错误密码不会产生相同密钥；单靠记录 PAKE 握手不能像普通密码加密文件那样离线验证大量候选码。主动攻击每次配对仍可尝试一个候选密码。房间仅允许一个接收方，协商失败客户端立即关闭该房间，发送方需要创建新码。知道 locator 的攻击者可以抢先占房，造成拒绝服务，不能因此获得正确密码下的文件。

服务端不知道秘密单词或共享密钥。服务端可以中断、拖慢、删除传输，但无法通过替换文件块生成有效 GCM 标签。PAKE 不保护遭到控制的客户端，也不防止通过不安全沟通渠道泄露完整接收码。

## 数据

- offer 内包含文件名、大小、分块计划和 SHA-256，使用 AES-256-GCM 加密。
- 独立块使用 AES-256-GCM。每个块索引有独立 HKDF 用途标签，AAD 包含 session UUID 和索引；每次加密使用随机 96 bit nonce。
- 块对象内容为 `nonce[12] || ciphertext || tag[16]`，因此比明文多 28 字节。
- 重试上传同一份密文；服务端签发 120 秒有效 URL，PUT 签名绑定 Content-Length 与 Content-Type。签名 URL 属于短期 bearer 凭据，应避免记录或分享。
- 对象 key 为 `transfers/{sessionUUID}/{index}`。服务端在 R2 HEAD 长度检查通过后才把块标记为 ready。
- 接收端可以在其他块仍上传时下载 ready 块，使用按块认证和 WriteAt 写入 `.part` 文件。
- 所有块完成后，重新计算整个文件的 SHA-256。核对后用硬链接原子发布文件，拒绝覆盖已有路径。macOS、Linux 和 Windows 分别需要支持硬链接的文件系统。
- 接收端发送加密完成回执，包含 SHA-256 与文件长度。发送端验证后请求清理云端对象。

Cloudflare 仍能看到源/目的 IP、传输时间、总文件大小、块数量、对象访问情况及控制请求量；文件名、校验值和内容在应用层加密。邀请令牌控制谁能创建传输，不作为文件加密密钥。

## 状态、过期和清理

双方在完成 PAKE 后保存自己恢复所需的会话密钥、角色令牌和文件计划。状态文件不包含长期 R2 凭据或部署邀请令牌，也不需要保存密码词。接收端还记录已同步写盘的块哈希；恢复时重新读盘验证，损坏的块重新下载。发送端恢复前检查源文件整体哈希，拒绝混入不同文件版本。

Windows 的 `0600` 不等价于 POSIX 权限隔离，恢复文件的访问控制依赖用户目录 ACL。请使用自己的私有目录。状态文件或内存密钥失窃会暴露当前会话文件。

会话默认从创建时起存活 2 小时，恢复不会延长。完成或拒绝后立即清理，并在 5 分钟后再次清理迟到上传；过期 alarm 与 bucket 的一天生命周期规则兜底。Cloudflare alarm 和生命周期操作都可能延迟，不能保证云端密文在某个精确时刻物理删除。

Worker / Durable Object 控制 API 不会验证 PAKE 数学或确认密钥；这些检查属于客户端。后端通过单次领取、消息不可变、角色授权和块长度约束限制操作，密码认证最终由双方客户端执行。

## 当前边界

- 当前传输路径仅为 R2，未实现 P2P / TURN。
- 初次配对要求双方在线。中断后有有效本地状态的一方可以恢复，仍需在原始 TTL 内。
- 普通单文件最大 2 GiB，最多 2048 个块。默认 16 MiB × 4 路并发，内存随块大小和并发增长，不把整个文件加载入内存。
- 临时 HTTP 连接问题会重试；GCM 或整文件校验失败会停止并保留部分文件供检查。
- 本地 Cloudflare 模拟器通过 Worker 代理对象，真实部署默认使用 R2 S3 预签名直传；部署后仍需验证真实 R2 权限、网络和时钟。
- 具有邀请令牌的人可以反复创建传输，免费额度不是硬性费用上限。本版面向受信任的小范围朋友，不是开放匿名文件托管服务。
